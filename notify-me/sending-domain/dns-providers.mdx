Open **Settings** in Notify Me, choose **View DNS records**, and copy **Host** and **Value** for both rows: the DKIM **TXT** and the bounce **CNAME**. Then pick your provider.

<Info>
  Paste **Host** exactly as Notify Me shows it. Most providers already append your domain. If Host is `@`, that is the root of the domain. Do not delete the A or CNAME records that point your shop to Shopify.
</Info>

## Cloudflare {#cloudflare}

Add both records from **View DNS records**.

<Steps>
  <Step title="Open DNS">
    Log in to [Cloudflare](https://dash.cloudflare.com), select the domain, then go to **DNS** → **Records**.
  </Step>
  <Step title="Add the DKIM TXT">
    Choose **Add record**. Set **Type** to **TXT**. Paste **Name** from Host and **Content** from Value. Save.
  </Step>
  <Step title="Add the bounce CNAME">
    Choose **Add record**. Set **Type** to **CNAME**. Paste **Name** from Host and **Target** from Value. Set **Proxy status** to **DNS only** (gray cloud), then save. Do not use the orange proxied cloud.
  </Step>
  <Step title="Verify in Notify Me">
    Back in Notify Me, choose **Check verification**.
  </Step>
</Steps>

## GoDaddy {#godaddy}

Add both records from **View DNS records**.

<Steps>
  <Step title="Open DNS">
    Log in to [GoDaddy](https://www.godaddy.com), open **My Products**, and choose **DNS** next to the domain.
  </Step>
  <Step title="Add the DKIM TXT">
    Choose **Add New Record**. Set **Type** to **TXT**. Paste **Name** from Host and **Value** from Value. Save.
  </Step>
  <Step title="Add the bounce CNAME">
    Choose **Add New Record**. Set **Type** to **CNAME**. Paste **Name** from Host and **Value** / **Points to** from Value. Save.
  </Step>
  <Step title="Verify in Notify Me">
    Back in Notify Me, choose **Check verification**.
  </Step>
</Steps>

## Shopify {#shopify}

Use this only if you bought the domain through Shopify or transferred it to Shopify. If the domain still lives at Cloudflare or GoDaddy, add records there instead.

<Steps>
  <Step title="Open DNS settings">
    In Shopify admin, go to **Settings** → **Domains**. Select the domain, then **DNS settings** (or **Manage**).
  </Step>
  <Step title="Add the DKIM TXT">
    Choose **Add custom record** → **TXT**. Paste **Name** from Host and **TXT value** from Value. Confirm.
  </Step>
  <Step title="Add the bounce CNAME">
    Choose **Add custom record** → **CNAME**. Paste **Name** from Host and **Points to** from Value. Confirm. Do not edit the default `www` CNAME that points the storefront to Shopify.
  </Step>
  <Step title="Verify in Notify Me">
    Back in Notify Me, choose **Check verification**.
  </Step>
</Steps>

## Amazon Route 53 {#amazon-route-53}

Add both records from **View DNS records**.

<Steps>
  <Step title="Open the hosted zone">
    In the [AWS console](https://console.aws.amazon.com/route53), go to **Route 53** → **Hosted zones**, then open the zone for your domain.
  </Step>
  <Step title="Add the DKIM TXT">
    Choose **Create record**. Set **Record type** to **TXT**. Paste **Record name** from Host and **Value** from Value. Create record.
  </Step>
  <Step title="Add the bounce CNAME">
    Choose **Create record**. Set **Record type** to **CNAME**. Paste **Record name** from Host and **Value** from Value. Create record.
  </Step>
  <Step title="Verify in Notify Me">
    Back in Notify Me, choose **Check verification**.
  </Step>
</Steps>

## Network Solutions {#network-solutions}

Add both records from **View DNS records**.

<Steps>
  <Step title="Open Advanced DNS">
    Log in to [Network Solutions](https://www.networksolutions.com), go to **Account Manager** → **My Domain Names**, select the domain, then **Advanced DNS**.
  </Step>
  <Step title="Add the DKIM TXT">
    In **Text (TXT Records)**, choose **Add TXT Record**. Paste **Host** from Host and **Text** from Value. Save.
  </Step>
  <Step title="Add the bounce CNAME">
    In **CNAME Records**, choose **Add CNAME Record**. Paste **Alias** / **Host** from Host and **Other Host** from Value. Save.
  </Step>
  <Step title="Verify in Notify Me">
    Back in Notify Me, choose **Check verification**.
  </Step>
</Steps>

<Note>
  DNS can take up to 48 hours. If your provider is not listed, look for **DNS**, **DNS Zone**, or **Advanced DNS**, then add a **TXT** and a **CNAME** with the Host and Value from Notify Me. Email [support@oneclickez.com](mailto:support@oneclickez.com) if you are stuck.
</Note>
