Mailchimp receives each **subscriber** as an audience member, plus join and alert events after Notify Me sends the email.

<Warning>
  Notify Me still sends the alert email. Mailchimp does not send it for you.
</Warning>

## Create an API key

Do this in Mailchimp, then paste the key into Notify Me. You need **Manager** (or Admin) permission.

<Steps>
  <Step title="Open API keys">
    In [Mailchimp](https://mailchimp.com), select your profile icon, then **Profile** (or **Account & billing**) → **Extras** → **API keys**.

    <Frame>
      ![Mailchimp Extras API keys page](/images/notify-me/mailchimp-extras-api-keys.png)
    </Frame>
  </Step>
  <Step title="Create a key">
    In **Your API Keys**, choose **Create A Key**. Name it `Notify Me`, then **Generate Key**.

    <Frame>
      ![Mailchimp Create A Key dialog](/images/notify-me/mailchimp-create-key.png)
    </Frame>
  </Step>
  <Step title="Copy the key">
    Choose **Copy Key to Clipboard**. Keep the suffix such as `-us21`. That is your data center. Mailchimp will not show the full key again. See [Mailchimp: about API keys](https://mailchimp.com/help/about-api-keys/).
  </Step>
</Steps>

<Info>
  New Mailchimp keys can expire after one year. If Test fails later, create a new key and replace it in Notify Me.
</Info>

## Connect in Notify Me

<Steps>
  <Step title="Open Integrations">
    In Notify Me, choose **Integrations** in the left nav, then **Connect** on Mailchimp.
  </Step>
  <Step title="Paste the key and test">
    Paste the API key and choose **Test**. When the test succeeds, pick the **Audience**.

    <Frame>
      ![Notify Me Connect Mailchimp modal with API key, Test, and Audience](/images/notify-me/integrations-connect-modal.png)
    </Frame>
  </Step>
  <Step title="Save">
    Choose **Save**. The Mailchimp card shows **Active**.
  </Step>
</Steps>

## What syncs

| When | Mailchimp event |
| --- | --- |
| Shopper becomes a subscriber | `waitlist_joined` |
| Notify Me sends a restock alert | `back_in_stock` |
| Notify Me sends a price drop alert | `price_drop` |

Use those event names in a Mailchimp automation. The member also gets product properties such as title, URL, and variant.

## Pause or disconnect

Choose **Manage** on the Mailchimp card.

- Turn off **Sync waitlist signups and alert events** to pause without removing the key. The badge shows **Inactive**.
- Paste a new key and **Test** to replace the current key.
- Choose **Disconnect** to remove the connection.
